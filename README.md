# THE REGULARS — website

Ένα σελιδοποιημένο, interactive site για το **The Regulars** — ανεξάρτητο digital agency με έδρα την Αθήνα.
Στατικό (HTML / CSS / vanilla JS), χωρίς build step, χωρίς dependencies.

```
index.html
assets/css/main.css     τα tokens της ταυτότητας + όλα τα components
assets/js/field.js      το scroll-driven γραφικό (canvas)
assets/js/main.js       πλοήγηση, γλώσσα, θέμα, διάγραμμα, calculator, φόρμα
```

Τρέξτε το τοπικά με οτιδήποτε σερβίρει στατικά αρχεία:

```bash
python3 -m http.server 8000     # → http://localhost:8000
```

## Πώς η ταυτότητα απαντά στο brief

**Ζεστή, όχι χαριτωμένη.** Βαθύ ζεστό μαύρο (`#0B0A09`) με κρεμ κείμενο και ember/χρυσό —
θερμοκρασία χωρίς παστέλ, χωρίς emoji, χωρίς στρογγυλεμένα «φιλικά» σχήματα.

**Διαρκής, όχι νοσταλγική.** Καμία ρετρό αναφορά: ο «θαμώνας» υπάρχει ως *ορισμός* στο hero
και ως *μαθηματικό* στο section «Τα μαθηματικά». Το μαγαζί είναι το νόημα της λέξης, όχι το σκηνικό.

**Οικεία και σοβαρή ταυτόχρονα.** Καθημερινή γλώσσα σε πρώτο πληθυντικό και χιούμορ
(«Λέξεις όπως “συνέργεια”, εκτός αν αστειευόμαστε») δίπλα σε ένα εργαλείο που υπολογίζει
contribution margin, breakeven και 12μηνη αξία πελάτη. Το ένα εμποδίζει το άλλο να γείρει.

**Αντέχει την κλίμακα.** Grid, τυπογραφική ιεραρχία και ένα διάγραμμα συστήματος που
λειτουργεί σε πρόταση 12 σελίδων· ταυτόχρονα κάθε section στέκει μόνο του σαν story.

**Ξεχωρίζει στο feed.** Το κινούμενο γραφικό (παρακάτω) δεν είναι διακοσμητικό gradient —
είναι μια μηχανή που αλλάζει κατάσταση όσο διαβάζετε.

**Δουλεύει εκτός Ελλάδας.** Διακόπτης **EL / EN** πάνω δεξιά· όλο το περιεχόμενο υπάρχει και στα δύο
(`data-en` σε κάθε μεταφράσιμο στοιχείο). Καμία έννοια δεν απαιτεί ελληνικό πολιτισμικό context.

## Το γραφικό που κινείται με το scroll

`assets/js/field.js` — ένα σύστημα σωματιδίων σε `<canvas>` που συμπεριφέρεται σαν μηχανή
που σκέφτεται φωναχτά. **Η θέση του scroll επιλέγει κατάσταση· η ταχύτητα του scroll είναι η φωνή του.**

| # | Κατάσταση | Πού εμφανίζεται | Τι λέει |
|---|-----------|-----------------|---------|
| 0 | **Σφαίρα** (fibonacci sphere, 3D περιστροφή) | hero | αδράνεια, παρουσία |
| 1 | **Κυματομορφή** (αρμονικές + γραμμή φωνής) | το όνομα / ο εχθρός | μιλάει |
| 2 | **Πλέγμα** με συνδέσεις | σύστημα / υπηρεσίες | «ένα σύστημα, όχι μενού» |
| 3 | **Τροχιές** (τρεις δακτύλιοι, κεκλιμένοι) | τα μαθηματικά | επανάληψη, επιστροφή |
| 4 | **Σπείρα** που συγκλίνει | πώς δουλεύουμε / εμείς / επικοινωνία | οι θαμώνες μαζεύονται |

Οι καταστάσεις κάνουν blend μεταξύ τους (smoothstep), όχι hard cut. Επιπλέον:
ripples όταν σκρολάρετε γρήγορα, parallax με το ποντίκι, aura που μετακινείται αργά.

Απόδοση: 180–900 σωματίδια ανάλογα με την επιφάνεια (λιγότερα σε κινητό), DPR καπάκι στο 2,
προ-rendered glow sprites αντί για gradient ανά σωματίδιο, παύση όταν το tab είναι κρυφό.
Με `prefers-reduced-motion: reduce` το canvas ζωγραφίζει **ένα** στατικό καρέ και όλα τα
animations του CSS απενεργοποιούνται.

## Interactive στοιχεία

- **Ο κύκλος LTV** (`#system`) — 6 βήματα, κλικ σε κόμβο ή σε γραμμή· αυτο-εναλλάσσεται μέχρι να το αγγίξετε.
- **Ο υπολογιστής** (`#math`) — sliders για AOV, περιθώριο, CAC και παραγγελίες/έτος.
  Δείχνει κέρδος 1ης παραγγελίας, κέρδος 12μήνου, σε ποια παραγγελία βγαίνει στα ίσια,
  και σωρευτικό κέρδος ανά παραγγελία. Είναι το επιχείρημα του brand σε μορφή εργαλείου.
- **Accordion υπηρεσιών** με δηλωμένη βαρύτητα (πυρήνας / υποστήριξη).
- **Θέμα σκούρο / ανοιχτό**, **EL / EN**, magnetic buttons, cursor glow, reveal-on-scroll,
  progress bar πλοήγησης, mobile menu.

## Τι πρέπει να συμπληρωθεί πριν το live

1. **Ονόματα ιδρυτών** — `index.html`, section `#us`: τα δύο `<article class="card card--person">`
   έχουν ρόλους αλλά όχι ονόματα (υπάρχει σχόλιο στο markup).
2. **Στοιχεία επικοινωνίας** — `hello@theregulars.gr` και `+30 210 000 0000` είναι placeholders
   (σε `#contact` και στη φόρμα).
3. **Φόρμα** — αυτή τη στιγμή συνθέτει `mailto:`. Για κανονική παραλαβή, δείξτε το `submit`
   handler του `assets/js/main.js` σε ένα endpoint (Formspree, Resend, δικό σας API).
4. **Fonts** — φορτώνονται από Google Fonts (Inter, Inter Tight, Literata, IBM Plex Mono,
   όλα με ελληνικά). Για self-hosting, κατεβάστε τα και αλλάξτε το `<link>` σε `@font-face`.
5. **OG image** — προστέθηκαν `og:title` / `og:description`· λείπει εικόνα.
